# Personal Finance Budget Status Prediction

## 📌 Project Overview

This project uses Machine Learning to predict a person's budget status based on their financial information such as income, expenses, savings, and other relevant factors.

The goal is to understand financial patterns and classify the budget status using Machine Learning techniques.

## 🎯 Objective

- Analyze personal financial data
- Perform data cleaning and preprocessing
- Explore patterns using Exploratory Data Analysis (EDA)
- Build and train Machine Learning models
- Evaluate model performance
- Predict the budget status

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔍 Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. Feature Selection
6. Model Training
7. Model Evaluation
8. Budget Status Prediction

## 🤖 Machine Learning

Machine Learning algorithms were applied to predict the budget status based on the available financial features.

The models were evaluated using appropriate classification performance metrics.

## 📊 Key Areas of Analysis

- Income Analysis
- Expense Analysis
- Savings Analysis
- Budget Status Distribution
- Feature Relationships
- Model Performance
